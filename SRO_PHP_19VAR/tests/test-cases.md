
#	Категория	Действие	Ожидаемый результат
1	Обычный сценарий	Заполнить форму корректно и отправить	Редирект на /my, flash «Вы успешно записаны», слот помечен «Занят»
2	Пустые значения	Отправить форму с пустым именем	Ошибка «Укажите имя», форма перерисована, данные сохранены
3	Некорректный email	Ввести not-an-email	Ошибка «Некорректный email»
4	Граничные значения	Имя из 1 символа	Ошибка «Имя слишком короткое»
5	Граничные значения	Комментарий 501 символ	Ошибка «Комментарий не длиннее 500 символов»
6	Некорректный тип	Отправить slot_id[]=s001 (массив)	normalize_string вернёт '', ошибка «Некорректный идентификатор»
7	Повторная отправка	Обновить страницу после успешной записи (PRG)	Дубль не создаётся, редирект остаётся на /my
8	Двойное бронирование	Прямой GET /?route=/book&slot_id=s001 по уже занятому слоту	HTTP 409 «Слот уже занят»
9	CSRF	Отправить POST без csrf	HTTP 403, операция отклонена
10	Чужой владелец	Войти с другим email и попытаться отменить чужую запись	Ошибка «Это не ваша запись»
11	Отмена < 60 мин	Попытаться отменить запись за 30 минут	Ошибка «Отмена возможна не позднее чем за 60 минут»
12	Хранилище	Испортить bookings.json	Flash/страница «Временная ошибка хранилища»
13	Слот в прошлом	Запрос на слот с прошедшей датой	HTTP 410 «Этот слот уже прошёл»
